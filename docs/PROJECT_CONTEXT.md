**문제 도메인의 정확한 구분:**
- `WM-811K`의 2D는 **웨이퍼 위 다이 위치·불량 패턴 맵**입니다.

## 2. U3 팀 surrogate 프로젝트의 큰 그림

**목적:** ViennaPS 시뮬레이션을 대신 계산하는 빠른 AI 대리 모델을 만들고, 후보를 검증/등록/서빙하며 공정 조건 변화 시 재학습과 회귀 게이트까지 연결하는 MLOps 파이프라인.

```text
C1 시뮬레이션 → C2 그래프/SDF 변환 → C3 AI 학습(FNO/MGN 등)
  → C4 형상·속도·신뢰성 평가 → C5 회귀 게이트(PASS/BLOCK)
  → C6 승인 모델 레지스트리 → C7 API → C9 대시보드
                             ↑
               C8 드리프트 감지 → 재학습·재검증
```

팀 기준 입력에는 플럭스 3종·이온 에너지·각도 지수·개구/마스크 치수 등 **7개 조건**이 등장합니다. 다만 팀원의 기하 변수 명칭, 조건 범위, 실제 시뮬레이션 시간, 모델 출력 형식, CD 정의와 게이트 정책은 서로 다릅니다. 단순히 `같은 7개 변수`라는 이유로 결과를 합치면 안 됩니다.

## 3. 조사 과정에서 드러난 공통 병목

1. **문서/코드 진도의 혼재:** 계획 체크리스트 `완료`와 실제 스모크 테스트 성공, 실제 FNO 모델 학습·승격은 다른 단계입니다.
2. **파일과 설정의 경계:** 원래 팀 파이프라인의 `dataset_hash`는 레시피 파라미터 목록으로 계산되어 실제 VTP 등의 내용 변경을 검출하지 못할 수 있습니다. 발견한 **검증 가설**이며, 팀 코드 수정/PR 전에 독립 결함 주입 테스트가 필요합니다.
3. **시간:** 팀 구현의 `step_min`(분)/일부 다른 구현의 `t_seconds`(초)/적응형 시뮬레이터 실제 저장 시각 간 차이가 있습니다.
4. **평가/골든 분리:** 성능이 val/test에서 좋아도 극단 조합의 독립 golden에서 실패하거나, 사후 정책 변경으로만 통과하는 문제가 있었습니다.
5. **재학습 증거:** `drift→retrain→BLOCK`과 `drift→retrain→PASS→promote→rollback`은 서로 다른 시연 목표입니다.
6. **환경:** 원본 실험 데이터·체크포인트가 Git에 없으면 CI 테스트 통과만으로 신규 clone에서 실모델 실행이 재현된 것은 아닙니다.

## 4. 이 개인 프로젝트에서 해결할 범위

**원래 생각한 후보:** 전체 ViennaPS C1–C9를 독립 재구현, 팀 저장소 포크/복제, 별도 FNO 웹 UI, 팀 공통 검증/승인 계층.

**채택:** 팀 프로젝트와 **보완적으로 결합 가능한 독립 EtchGuard**. 현 단계는 Python 표준 라이브러리만으로 `data contract → fingerprint → baseline → metrics → gate → registry → report`까지 실행 가능한 P0를 만드는 것. 이후 실제 ViennaPS parser/adapter를 추가하되, 기존 시험/코드를 깨뜨리지 않음.

**배경:** 전체 C1–C9 독립 구현은 시간과 compute가 많이 들고 팀원 중복도가 높습니다. 포크는 빠르게 UI를 얻을 수 있지만 프로젝트 독립 기여 및 원본 artifact 재현에 제약이 있습니다. 검증 계층은 팀 데이터·모델을 실제로 연결할 때 재사용할 수 있습니다.

## 5. 본인 업무/기여의 기준

- **본인 코드/증거:** 독립 구현한 EtchGuard, 테스트, 실제 실행 로그, GitHub 커밋과 CI.
- **팀원 선행 연구:** 아이디어·코드 구조·실험 데이터·미검증 항목을 출처와 함께 참조. 직접 재검증하지 않은 수치는 `팀원 보고`.
- **앞으로의 통합:** 팀원 model checkpoint·VTP 원본을 무조건 다운로드/복사하지 않음. 권한·라이선스·단위·연산 정의를 확인한 **어댑터 기반 재현**.
- **개인 진행 기록:** 설계 결정, 오류/해결, 실행 명령, 커밋 SHA, 미완료가 항상 남아야 합니다. AI-generated code 사용 내역도 기여 기록에서 투명하게 다룹니다.
